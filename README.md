# Take Off Your Shorts

Расширение для **Chromium** (Chrome, Edge, Brave, Vivaldi и т.п.), которое убирает из интерфейса YouTube:

- пункт **Shorts** в боковом меню;
- горизонтальный **блок Shorts** в ленте.

Прямой переход по ссылке на `/shorts/…` расширением не блокируется.

## Установка из исходников

1. Клонируйте репозиторий или скачайте архив.
2. Откройте `chrome://extensions` (или `edge://extensions`).
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и укажите папку `extension/` из этого проекта.

Обновление после правок кода: на странице расширений нажмите **Обновить** у карточки расширения.
